# pyai.site

基于 [Astro](https://astro.build) 的中英双语静态站点，自动部署到 [GitHub Pages](https://pyai.site)。

## 内容

* **记录** — 文章/随笔/笔记，用标签区分类型（中英双语）

- **项目** — 一些开源作品
- **观影** — 豆瓣观影记录，每日自动同步，含统计
- **关于** — 关于本人与本站

## 技术栈

Astro 7 · Tailwind CSS 4 · TypeScript · GitHub Pages · pnpm
